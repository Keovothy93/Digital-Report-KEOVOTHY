1. Extract ZIP ទាំងមូល។ បើក index.html ជាមួយ Chrome ឬ Edge។
2. ជ្រើសខែ និង Platform: Facebook / TikTok / YouTube / Website។
3. ទម្លាក់ឯកសារ ឬចុច «បញ្ចូល KPI ដោយផ្ទាល់»។
4. ចុច «ភ្ជាប់ Gemini» បញ្ចូល API Key របស់បង រួចចុច «រួចរាល់»។
5. ចុច «វិភាគរបាយការណ៍»។ ពិនិត្យ KPI / ការពន្យល់ / ផែនការបន្ទាប់។

ការបញ្ចូល KPI ដោយផ្ទាល់
- បញ្ចូលឈ្មោះ Page / អាជីវកម្ម។
- ជ្រើស Platform ហើយបញ្ចូលឈ្មោះ KPI ជាមួយឯកតា ឧ. Reach (people), Spend (USD), CTR (%)។
- «ខែនេះ» ត្រូវបញ្ចូល។ ខែមុន និងគោលដៅអាចទុកទទេ ប្រសិនបើគ្មានទិន្នន័យ។
- ចំនួន 0 ជាលទ្ធផលសូន្យពិតប្រាកដ; ទុកទទេមានន័យថាមិនមានទិន្នន័យ។
- ទិសដៅ៖ Reach / Sales ជាទូទៅចង់បានខ្ពស់។ CPC / CPA ជាទូទៅចង់បានទាប។ ជ្រើសតាមគោលដៅជាក់ស្ដែង។
- អាចបន្ថែមរហូតដល់ 40 KPI ក្នុងមួយទម្រង់។
- បម្រែបម្រួល = (ខែនេះ − ខែមុន) ÷ ខែមុន × 100។ មិនគណនាភាគរយនៅពេលខែមុនសូន្យ ឬទទេ។
- «ទាញយក CSV» រក្សាលេខដែលបញ្ចូលបាន ដោយមិនត្រូវការ Internet ឬ API Key។
- «បន្ថែមទៅរបាយការណ៍» បម្លែងទិន្នន័យជាឯកសារ CSV សម្រាប់ AI វិភាគ។
- ទម្រង់រក្សាការបញ្ចូលនៅពេលបិទ/បើកក្នុង Tab ដដែល ប៉ុន្តែមិនរក្សាទុកក្រោយ Reload។ បើបន្ថែមកំណែថ្មី សូមលុប CSV កំណែចាស់ចេញពីបញ្ជីឯកសារ ដើម្បីកុំឱ្យទិន្នន័យជាន់គ្នា។

VERSION 6 — SAVE, MULTI-MONTH & NOTES
- ខែដែលត្រូវវិភាគ៖ ជ្រើសខែមួយ រួចចុច «+ បន្ថែម»។ អាចបន្ថែមខែច្រើន និងដកចេញតាមប៊ូតុង ×។
- ខែត្រូវបានរៀបតាមលំដាប់ពេលវេលា។ តារាង KPI ប្រៀបធៀបខែចុងក្រោយនឹងខែមុនដែលបានជ្រើស។ ខែផ្សេងៗត្រូវបានណែនាំឱ្យ AI ពន្យល់និន្នាការ; មិនមានជួរឈរដាច់ដោយឡែកសម្រាប់គ្រប់ខែទេ។
- បញ្ចូលឯកសារដែលមានទិន្នន័យគ្រប់ខែដែលជ្រើស។ គ្រាន់តែជ្រើសខែមិនបង្កើតទិន្នន័យឱ្យខែនោះទេ។
- ក្នុងទម្រង់ KPI ដោយផ្ទាល់ ជ្រើសខែសម្រាប់ឯកសារនីមួយៗ។
- Save & Notes មាននៅក្រោមផ្ទាំងបញ្ចូលទិន្នន័យ។ បញ្ចូលឈ្មោះការងារ ហើយចុច «Save ទុកប្រើថ្ងៃក្រោយ»។
- Save នីមួយៗបង្កើតច្បាប់ចម្លងថ្មី រក្សាខែ Platforms context Note ឯកសារដែលបានបញ្ចូល និងលទ្ធផលវិភាគ។ ចុច Save ម្ដងទៀតក្រោយកែប្រែ។
- KPI នៅក្នុងទម្រង់ត្រូវចុច «បន្ថែមទៅរបាយការណ៍» មុន Save។
- ប៊ូតុង «បើក» ស្ដារការងារ។ ប៊ូតុង «លុប» សួរបញ្ជាក់មុនលុប Save នោះ។
- Save រក្សាក្នុង IndexedDB របស់ Browser និងឧបករណ៍នេះ។ ការលុបទិន្នន័យ Browser, private browsing ឬការផ្លាស់ទីឯកសារ/URL អាចធ្វើឱ្យមើល Save ចាស់មិនឃើញ។
- «Backup JSON» ទាញយកការងារបច្ចុប្បន្នរួមទាំងឯកសារ។ «បើក Backup» ស្ដារការងារពី JSON លើឧបករណ៍ផ្សេងបាន។
- API Key មិនត្រូវបាន Save ឬបញ្ចូលក្នុង Backup ទេ។
- Note មានអត្ថបទ “Make Monthly Report Jul Vs Aug” តាមសំណើ។ អាចកែដោយផ្ទាល់ និងចុច «Copy Note»។ Note មិនផ្លាស់ប្ដូរតាមខែស្វ័យប្រវត្តិ និងមិនផ្ញើទៅ AI ទេ; ប្រើ context បើចង់ផ្ញើការណែនាំទៅ AI។
- បានត្រួតពិនិត្យ syntax, multi-month selection, manual KPI month, និង Backup/restore round trip ក្នុងការសាកល្បងកូដ។ Browser UI, IndexedDB ជាក់ស្ដែង និង Gemini API មិនទាន់បានសាកល្បង។
