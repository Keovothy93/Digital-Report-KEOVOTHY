SOCIAL PERFORMANCE REPORT

របៀបប្រើ
1. Extract ZIP ទាំងមូលទៅ Folder មួយ។
2. បើក index.html ក្នុង Chrome ឬ Edge។ រក្សា app.js, engine.js, styles.css និង Folder vendor នៅជាមួយគ្នា។
3. Upload File .xlsx / .csv / .tsv ពី Facebook, TikTok ឬ YouTube។
4. ជ្រើស Sheet, ម៉ាក, Platform, Organic/Paid/Total និងរយៈពេលដែលបាន Export។ ពិនិត្យ Column mapping មុននាំចូល។
5. ចូល Performance ដើម្បីជ្រើសតម្រង និងមើលលទ្ធផល។
6. ចូល របាយការណ៍ប្រជុំ ដើម្បីកត់សកម្មភាព និងទាញយក Excel ឬ Print / Save PDF។

បញ្ជាក់
• ទាញយក Backup មុនបិទ ឬ Reload ទំព័រ។ File ZIP មានកម្មវិធី មិនមានទិន្នន័យ Report របស់បងទេ។
• កម្មវិធីមិនទាញ Report ពីគណនី Platform ស្វ័យប្រវត្តិ។
• Excel reader មាននៅក្នុង vendor ដូច្នេះមិនចាំបាច់ដំឡើងបន្ថែម។ Font ពី Google ត្រូវការ Internet; ពេល Offline ប្រើ Font ក្នុងកុំព្យូទ័រ។
