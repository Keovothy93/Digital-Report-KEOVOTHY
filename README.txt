AI (ឥតគិតថ្លៃ) — របៀបយក API Key
• ចូល https://aistudio.google.com/apikey ដោយ Account Google ធម្មតា (មិនចាំបាច់ដាក់កាតឥណទាន)។
• ចុច Create API key ហើយចម្លងមកដាក់ក្នុងប្រអប់ "API Key" នៅក្នុងគេហទំព័រ។
• Key ត្រូវបានរក្សាទុកតែក្នុង Browser របស់បង (localStorage) ប៉ុណ្ណោះ។ វាមិនត្រូវបានផ្ញើទៅ Server ណាក្រៅពី Google ទេ ព្រោះកម្មវិធីនេះគ្មាន Backend។ កុំចែក Key នេះជាមួយអ្នកដទៃ។
• Free tier របស់ Google Gemini មានកម្រិត Request ក្នុងមួយនាទី/ថ្ងៃ។ ប្រសិនបើលើសកម្រិត សូមរង់ចាំបន្តិច ហើយសាកម្ដងទៀត។
• AI សរសេរសេចក្ដីសង្ខេបពីលេខសរុបប៉ុណ្ណោះ (មិនមែនទិន្នន័យផ្ទាល់ខ្លួនអតិថិជនទេ)។ សូមអានផ្ទៀងផ្ទាត់មុនយកទៅប្រជុំ ព្រោះ AI អាចខុសពេលខ្លះ។
